# App configurations

Per-application configs for OkSelenized. Files named `okselenized-*` are
generated by `../okselenized.py` — edit the generator, not the files.
The rest are hand-maintained.

Most terminal apps need nothing — they use ANSI colors as foregrounds and
just work once the terminal palette is applied. The entries below are the
ones that need a file or a nudge.

## Windows Terminal

`windows-terminal.json` contains all three variants as color schemes.
Open Settings (`Ctrl+,`) → "Open JSON file", copy the objects from the
`"schemes"` array into your settings' `"schemes"` array, then pick
"OkSelenized dark" (or black/light) as the color scheme of a profile —
via the settings UI or `"colorScheme": "OkSelenized dark"` on the profile.

## Cygwin / MSYS2 (mintty)

For the running session, `python3 ../apply.py {black|dark|light}` works
as-is — mintty supports the OSC sequences. To make one variant permanent,
append its minttyrc to your config:

```sh
cat okselenized-dark.minttyrc >> ~/.minttyrc
```

New mintty windows pick it up on start.

## IntelliJ / JetBrains IDEs

`okselenized-{dark,black,light}.icls` are editor color schemes. Import via
Settings → Editor → Color Scheme → gear icon → Import Scheme. Because
IntelliJ derives per-language colors from the `DEFAULT_*` attributes, this
small scheme themes every language; dark/black inherit the rest from
Darcula, light from the Default scheme. The IDE *UI* (menus, tool windows)
stays on the built-in Dark/Light theme — a full UI theme would need a
plugin and is not provided.

## Notepad++

No generated theme file yet: Notepad++ does not inherit per-token colors
from a global default, so a proper theme means spelling out lexer styles
for every language (the reason published N++ themes are ~1500-line XMLs).
Until then, the practical route is the Style Configurator
(Settings → Style Configurator → Global Styles): set "Default Style" to
fg `#b3bdc0` / bg `#1c3b44` (dark) and map tokens with the same
assignments the other configs use:

| Token | Slot | dark hex |
|---|---|---|
| comments | dim_0 | `#7b8b90` |
| keywords | green | `#70a843` |
| strings | cyan | `#26ab9e` |
| numbers/constants | violet | `#a480db` |
| functions/tags | blue | `#5097ef` |
| classes/types | yellow | `#b4910a` |
| annotations | orange | `#d67943` |

(Hex values for black/light are in the `../okselenized-*.json` files.)

## oh-my-bash

`okselenized.theme.sh` is a prompt theme based on
[duru](https://github.com/ohmybash/oh-my-bash/wiki/Themes#copied-duru),
showing the full working directory (home spelled out) instead of the last
two components. Colors are ANSI slots, so it follows the applied variant.

```sh
mkdir -p ~/.oh-my-bash/custom/themes/okselenized
cp okselenized.theme.sh ~/.oh-my-bash/custom/themes/okselenized/
# then in ~/.bashrc: OSH_THEME="okselenized"
```

## mc, newt/whiptail (shell rc)

Source `okselenized.rc` from your shell rc:

```sh
. /path/to/configurations/okselenized.rc
```

- **mc** — the default skin paints panels with ANSI blue as background
  (glaring with any lightness-normalized palette, Selenized included).
  Sets `MC_SKIN=modarcon16-defbg`, which uses the 16 terminal colors on
  the terminal's own background.
- **newt/whiptail** (debconf, needrestart, …) — dialogs default to
  white-on-blue. Sets `NEWT_COLORS` remapped onto this palette's slot
  semantics (adapted from
  [selenized#130](https://github.com/jan-warchol/selenized/issues/130)).
  Test with `whiptail --msgbox test 10 40`.

## aptitude

Defaults to white-on-blue menu/header bars
([selenized#32](https://github.com/jan-warchol/selenized/issues/32)).
Can't be fixed via environment: copy `aptitude.config` to
`~/.aptitude/config` (or merge it into your existing one).

## Not themeable (so you stop looking)

- **Windows Explorer** — follows the system light/dark mode and single
  accent color only; closest match: dark mode + accent `#5097ef`.
- **Windows taskbar** — "Show accent color on Start and taskbar" is only
  offered in dark system mode; in light mode the taskbar is a fixed grey.
  Workaround: [TranslucentTB](https://github.com/TranslucentTB/TranslucentTB)
  (Microsoft Store) paints it any hex, e.g. `#fcf3db` for light.
- **OneNote** — Office theme switch and a fixed page-color palette only.
- **SumatraPDF** — partial: `Settings → Advanced Options` supports
  `MainWindowBackground = #1c3b44` and a reading mode via
  `FixedPageUI { TextColor = #b3bdc0; BackgroundColor = #1c3b44 }`;
  the rest of the UI follows its built-in light/dark themes.
